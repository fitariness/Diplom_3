# Diplom_3 — UI-тесты Stellar Burgers

В этой части проверяется пользовательский интерфейс [Stellar Burgers](https://stellarburgers.education-services.ru/)

Тесты написаны на `pytest` и `selenium`, страницы описаны через Page Object, шаги оформлены через `allure-pytest`. Проверки вынесены в `helpers/checkers.py`, а тестовые пользователи и заказы подготавливаются через API

## Зависимости

```bash
pip install -r requirements.txt
```

Нужны установленные **Google Chrome** и **Mozilla Firefox**.

## Запуск тестов

```bash
pytest
```

Тесты выполняются в Chrome и Firefox (параметризация в `conftest.py`).

Запуск только в одном браузере:

```bash
pytest -k chrome
pytest -k firefox
```

## Allure-отчёт

```bash
pytest --alluredir=allure-results
allure serve allure-results
```

## Структура проекта

- `locators/` — локаторы элементов
- `pages/` — Page Object (действия на страницах)
- `helpers/` — API-хелперы, checkers
- `tests/` — автотесты
  - `test_constructor.py` — конструктор
  - `test_order_feed.py` — лента заказов

## Что проверяется

**Конструктор**

- переход из ленты заказов в конструктор
- переход из конструктора в ленту заказов
- открытие модального окна ингредиента по клику
- закрытие модального окна ингредиента по крестику
- увеличение счётчика ингредиента после добавления в заказ
- оформление заказа авторизованным пользователем

Проверки ингредиентов выполняются для трёх типов:

- булка
- соус
- начинка

**Лента заказов**

- увеличение счётчика «Выполнено за всё время» после создания заказа
- увеличение счётчика «Выполнено за сегодня» после создания заказа
- появление номера созданного заказа в разделе «В работе»

## Что проверяется на страницах

- текущий URL после перехода
- активная ссылка в шапке
- заголовок открытой страницы
- заголовок модального окна ингредиента
- закрытие модального окна
- рост счётчиков ингредиентов и заказов
- номер заказа в модальном окне и в ленте
